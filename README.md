# @sentropic/bpmn-canvas

Provisional name. Framework-independent BPMN 2.0 editing canvas built on
[bpmn-js](https://github.com/bpmn-io/bpmn-js), with optional React and
assistant-ui adapters.

Status: scaffold (phase P0). No public API is frozen yet.

The bpmn.io watermark required by the bpmn-js license is kept visible and
linked on every canvas instance. See `THIRD_PARTY_NOTICES.md`.
