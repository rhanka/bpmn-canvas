3. `pyFloatStr` (Python `repr(float)`): `1250→"1250.0"`, `0.1+0.2→"0.30000000000000004"`, `123.456→"123.456"`,
   `−0.0→"-0.0"`; `≥1e16` and `0<|x|<1e-4` refused (outside the emulated range).
4. Escaping table, one input for every row: `` a&b<c>d"e'f `` + LF + CR + TAB.
   - ElementTree **attribute**: `a&amp;b&lt;c&gt;d&quot;e'f&#10;&#13;&#09;`.
   - ElementTree **text**: `a&amp;b&lt;c&gt;d"e'f` + LF + CR + TAB kept raw (`"` and control whitespace not escaped).
   - minidom **attribute** and **text** (Python ≤ 3.12 `_write_data`): `a&amp;b&lt;c&gt;d&quot;e'f` + LF + CR + TAB

     `&#10; &#13; &#09;` in the ElementTree attribute only.
5. ElementTree writer: prologue `<?xml version='1.0' encoding='utf-8'?>\n`; attributes in insertion order; `$`,

## Decisions Q1–Q7 (accepted)
- **Q1** `served` belongs to the current `xml` and is passed with it; a new non-echo document invalidates it; stale
  responses are rejected by the host (lot D1).
- **Q2** API: `not-served`, codec not run; workshop: the item is disabled per format.
- **Q3** Reference Sparx codec: `application/xml`; the passthrough keeps the received mime type.
- **Q4** Layout corpus: invented base cases only.
- **Q5** Step-0 structure fixture: limited extraction (toolbar/menus, UI strings, SVG paths; no project classes or
  ids, no diagram text).
- **Q6** Codes as listed in §2.5, with the expected code and ids per refusal; never a partial file; BPMN always
  exportable.
- **Q7** As in §3.6: the edited type and `flowNodeRef` take priority; a rename keeps the facts by id.
