## Proof rules for every function

- Hand-authored, wholly invented expected semantics accompany each fixture. Existing C1–C7 emitter goldens are regression evidence, not an independent parity oracle.
- Freeze explicit configuration and hash descriptors, rules, metrics, profile and envelopes as applicable. Run three repeats in fresh runtimes and A→B→A case/configuration order; no first-call singleton, environment, locale, clock, randomness or DOM measurement may choose output.
- Compare input hashes before/after, including ordered containment, references, extensions, DI and styles. Reject invalid inputs with deterministic typed code, target IDs and structural path; return no partial output.
- Canonical JSON sorts object keys recursively, preserves every array order/string, and uses the G0 shortest round-trip decimal representation without exponents and normalizes negative zero to 0.
- Identity/fixed points apply to well-typed compositions only. F2/F5/F6/F7 outputs cannot be fed directly back into those functions.
- G0 is mirrored under `tests/fixtures/parity-corpus/` without edits, including its 69-entry manifest. G1/G2 corpus comparisons execute in separate parity suites. Python execution receipt hashes remain pending their location; independently authored expected results are not relabeled as captured runtime outputs.

## Local F1 policy and API decisions

Names follow the design: `hydrate`, `project`, `serializeBpmn`, exported from the package IO entry (and its existing browser re-export). Configuration is passed on every native call. F1 configuration pins contract version `1`, a registered descriptor map and default policy `explicit`. Known descriptor defaults are emitted explicitly; inputs already containing them have exact identity. Omitted known defaults are expanded visibly, and the expanded JSON is a fixed point. Optional absent fields and explicit empty arrays remain distinct. Descriptor numeric defaults are converted to their declared number type. This local policy must be checked against the shared G0 policy before any parity acceptance.

Optional unknown attributes/extensions have no cross-runtime preservation proof yet: refuse explicitly. Registered namespace declarations in `$attrs` are preserved; unknown namespace/version declarations are refused. Typed registered colors live in descriptor properties. Required `sem` uses the shipped descriptor version. No business lint or emitter support restriction is substituted for F1 integrity.
